# Vehicle test: 2018 Audi Q5 — US `MHI2Q_US_AUG22_P4246`, MU 1320

## Vehicle & head unit

- **Vehicle:** 2018 Audi Q5, USA / North America market.
- **Head unit:** MHI2Q.
- **Firmware train:** `MHI2Q_US_AUG22_P4246` (AUG22).
- **MainUnit (MU) version:** `1320`.
- **Phone:** iPhone 16 Pro, iOS 27.0.1
- **Phone connection:** wired CarPlay (USB)

## Release

- **Release:** V3.8 (`V3.8.zip`, tag `v3.8`, commit `141e7ed`)
- **SHA-256:** `62c59e364fb5812fc1d49768c0fc4dbbafcd45de3f6739d0263ed9ca98e1291f`

## Installation

- **Install mode:** INSTALL WITH RGI CARD ("AltScreen + RGI + phone card").
- **Method:** installed **over SSH** from the internal staging volume
  `/mnt/ota/carplay-altscreen` — no SD card. See "How this was installed"
  below.
- The installer reported `OK - firmware 'MHI2Q_US_AUG22_P4246'` and
  `RESULT: SUCCESS`.
- **Activation:** one full head-unit power cycle after install, as
  required by the installer.

## Results

Observed after activation (from on-unit logs):

- GPU `direct111` mirror pipeline active; stock map plane clipped 1:1;
  Context 80 owned by the Java HMI; ~15.9 fps presented.
- Steering-wheel zoom working (`ZOOM_IN` / `ZOOM_OUT`, magnification
  steps).
- RGI route-guidance updates received with no errors; maneuver renderer
  running.
- Cluster telephone tab populated with CarPlay recents and favorites.
- Clean session `STOP` with no restart loop when the phone
  disconnected.
- No audio problems observed during use; cluster map quality good.

## Open items

- `/tmp/altscreen_boot_entry.log` ended with a `Killed` line from a
  bounded boot-diagnostic child being reaped; OEM boot and the AltScreen
  runtime were unaffected. Harmless so far; not yet root-caused.

## How this was installed

The install went over SSH into the internal staging volume instead of
an SD card — see [Tools/ansible](../../Tools/ansible/README.md). The
same flow works for `status / stage / install / restore / logs` and
never reboots the unit automatically.

> The install flow (stage → verify → installer → fetch backup) was used
> on this vehicle through an equivalent earlier version of that
> playbook.
